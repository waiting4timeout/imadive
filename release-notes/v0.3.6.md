Imadive 0.3.6 can back up everything the gallery has learned, and update itself from Settings.

## Downloads

- **Windows 10/11**: `Imadive-0.3.6-windows-x64.exe`. Double-click it. It is not signed, so the first time Windows may show "Windows protected your PC": click **More info**, then **Run anyway**.
- **Debian, Ubuntu and Linux Mint** (Debian 12 or Ubuntu 22.04 or newer): `Imadive-0.3.6-linux-amd64.deb`. Install it with `sudo apt install ./Imadive-0.3.6-linux-amd64.deb`, then start Imadive from the applications menu.
- **Other Linux distributions (x86-64)**: `Imadive-0.3.6-linux-x86_64.AppImage`. Run `chmod +x Imadive-*.AppImage`, then start it. If it says FUSE is missing, install `libfuse2` or run it with `--appimage-extract-and-run`.
- **A Linux server** (x86-64, or ARM64 such as a Raspberry Pi 4 or 5): `Imadive-server-0.3.6-linux-x86_64.tar.gz` or `…-linux-aarch64.tar.gz`, installed by the one-line command in the [server guide](https://github.com/waiting4timeout/imadive/blob/main/docs/server.md).

Your folders, people names and index carry over from earlier versions; nothing is indexed again.

Each download can be checked: `SHA256SUMS` lists the files' checksums, and every file carries a signed record of the GitHub build it came from (`gh attestation verify <file> --repo waiting4timeout/imadive`).

## What's new

- **Backups** of everything the gallery has learned that the photos themselves don't say: people and their names, the face groups, the faces you placed (*Not them*, *Same as…*), card photos, hidden people, items removed from the gallery, and the list of folders. The photos and videos are not in it: back them up on their own. *Back up…* (Settings → Library) saves a dated file — on a server, into one of its folders; in the desktop app, wherever the save dialog points — with its progress shown while the gallery keeps working. *Restore…* says what a backup holds before anything changes, and can bring it back here or on another computer; the index it replaces is kept beside it, in case the restore wasn't wanted. A backup made on a phone's browser, say, can be uploaded into a server's gallery too.
- **Updates from Settings**: it says whether a newer release than yours is out, with *Check for updates* to look now and, when there is one, *What's new* (its release notes) and *Update*. Imadive looks on GitHub a minute after it starts and then once a day — the only network request it makes by itself, which `--no-update-check` or `IMADIVE_NO_UPDATE_CHECK=1` turns off. The update installs with one click: the desktop apps replace themselves, and a server installed with `imadive setup` is updated by a small service of setup's and restarted. A server built from source is told how to switch to the ready-made one; with Docker, Settings says to `docker pull`.
