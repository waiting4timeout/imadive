Imadive 0.4.6 is the same app as 0.4.5, with its insides organized better.

## Downloads

- **Windows 10/11**: `Imadive-0.4.6-windows-x64.exe`. Double-click it. It is not signed, so the first time Windows may show "Windows protected your PC": click **More info**, then **Run anyway**.
- **Debian, Ubuntu and Linux Mint** (Debian 12 or Ubuntu 22.04 or newer): `Imadive-0.4.6-linux-amd64.deb`. Install it with `sudo apt install ./Imadive-0.4.6-linux-amd64.deb`, then start Imadive from the applications menu.
- **Other Linux distributions (x86-64)**: `Imadive-0.4.6-linux-x86_64.AppImage`. Run `chmod +x Imadive-*.AppImage`, then start it. If it says FUSE is missing, install `libfuse2` or run it with `--appimage-extract-and-run`.
- **A Linux server** (x86-64, or ARM64 such as a Raspberry Pi 4 or 5): `Imadive-server-0.4.6-linux-x86_64.tar.gz` or `…-linux-aarch64.tar.gz`, installed by the one-line command in the [server guide](https://github.com/waiting4timeout/imadive/blob/main/docs/server.md).

Your folders, people names and index carry over from earlier versions; nothing is indexed again.

Each download can be checked: `SHA256SUMS` lists the files' checksums, and every file carries a signed record of the GitHub build it came from (`gh attestation verify <file> --repo waiting4timeout/imadive`).

## What's new

- Nothing you'll notice: this is a maintenance release. The code inside was reorganized — the scan one function per phase, the work that changes the library through one state, Settings' cards and the setup and update wizards each in their own modules, and the face grouping apart from the database — so the next changes are easier to make.
