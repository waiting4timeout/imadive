Imadive 0.4.11 fixes typing a year by hand, and the demo loop on the README shows the slideshow.

## Downloads

- **Windows 10/11**: `Imadive-0.4.11-windows-x64.exe`. Double-click it. It is not signed, so the first time Windows may show "Windows protected your PC": click **More info**, then **Run anyway**.
- **Debian, Ubuntu and Linux Mint** (Debian 12 or Ubuntu 22.04 or newer): `Imadive-0.4.11-linux-amd64.deb`. Install it with `sudo apt install ./Imadive-0.4.11-linux-amd64.deb`, then start Imadive from the applications menu.
- **Other Linux distributions (x86-64)**: `Imadive-0.4.11-linux-x86_64.AppImage`. Run `chmod +x Imadive-*.AppImage`, then start it. If it says FUSE is missing, install `libfuse2` or run it with `--appimage-extract-and-run`.
- **A Linux server** (x86-64, or ARM64 such as a Raspberry Pi 4 or 5): `Imadive-server-0.4.11-linux-x86_64.tar.gz` or `…-linux-aarch64.tar.gz`, installed by the one-line command in the [server guide](https://github.com/waiting4timeout/imadive/blob/main/docs/server.md).

Your folders, people names and index carry over from earlier versions; nothing is indexed again.

Each download can be checked: `SHA256SUMS` lists the files' checksums, and every file carries a signed record of the GitHub build it came from (`gh attestation verify <file> --repo waiting4timeout/imadive`).

## What's new

- **A year typed by hand is taken as it's meant.** While a year is being typed, the browser reports half-written numbers like 0002, 0020 and 0202 as dates; each used to be applied as the date range, and writing it back started the typing over, leaving the field empty. Now a year below 1000 is taken for a year being typed and not applied, and a half-typed year goes back to the date in use.
- **The demo loop on the project page shows the slideshow.** After one person's photos, it plays them as a slideshow: the bar comes up, the speed goes to the fastest, and a few photos fade into each other.
