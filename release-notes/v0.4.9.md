Imadive 0.4.9 shows the filtered photos and videos one after another, full screen, and is now free and open-source software under the GNU AGPL-3.0.

## Downloads

- **Windows 10/11**: `Imadive-0.4.9-windows-x64.exe`. Double-click it. It is not signed, so the first time Windows may show "Windows protected your PC": click **More info**, then **Run anyway**.
- **Debian, Ubuntu and Linux Mint** (Debian 12 or Ubuntu 22.04 or newer): `Imadive-0.4.9-linux-amd64.deb`. Install it with `sudo apt install ./Imadive-0.4.9-linux-amd64.deb`, then start Imadive from the applications menu.
- **Other Linux distributions (x86-64)**: `Imadive-0.4.9-linux-x86_64.AppImage`. Run `chmod +x Imadive-*.AppImage`, then start it. If it says FUSE is missing, install `libfuse2` or run it with `--appimage-extract-and-run`.
- **A Linux server** (x86-64, or ARM64 such as a Raspberry Pi 4 or 5): `Imadive-server-0.4.9-linux-x86_64.tar.gz` or `…-linux-aarch64.tar.gz`, installed by the one-line command in the [server guide](https://github.com/waiting4timeout/imadive/blob/main/docs/server.md).

Your folders, people names and index carry over from earlier versions; nothing is indexed again.

Each download can be checked: `SHA256SUMS` lists the files' checksums, and every file carries a signed record of the GitHub build it came from (`gh attestation verify <file> --repo waiting4timeout/imadive`).

Free and open-source software under the [GNU AGPL-3.0](https://github.com/waiting4timeout/imadive/blob/main/LICENSE). The face recognition models built into the app are for non-commercial use only (see [THIRD_PARTY.md](https://github.com/waiting4timeout/imadive/blob/main/THIRD_PARTY.md)).

## What's new

- **A slideshow of the filtered photos and videos.** A button next to the photo count shows the photos and videos of the current filters one after another, full screen: photos crossfade, a video plays to its end. Moving the mouse or touching the screen brings up a bar to show them in order or shuffled, set the speed (20 to 2 seconds a photo) and stop it; Esc and Back stop it too, and the arrows move by hand. The order and speed are remembered.
- **The license is now the GNU AGPL-3.0** instead of PolyForm Noncommercial: Imadive is free and open-source software, for any purpose, commercial ones included.
