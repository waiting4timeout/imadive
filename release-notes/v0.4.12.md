Imadive 0.4.12 makes a date range replace an open year, month or day, and updates the app's dependencies, with the SQLite inside patched for a published vulnerability.

## Downloads

- **Windows 10/11**: `Imadive-0.4.12-windows-x64.exe`. Double-click it. It is not signed, so the first time Windows may show "Windows protected your PC": click **More info**, then **Run anyway**.
- **Debian, Ubuntu and Linux Mint** (Debian 12 or Ubuntu 22.04 or newer): `Imadive-0.4.12-linux-amd64.deb`. Install it with `sudo apt install ./Imadive-0.4.12-linux-amd64.deb`, then start Imadive from the applications menu.
- **Other Linux distributions (x86-64)**: `Imadive-0.4.12-linux-x86_64.AppImage`. Run `chmod +x Imadive-*.AppImage`, then start it. If it says FUSE is missing, install `libfuse2` or run it with `--appimage-extract-and-run`.
- **A Linux server** (x86-64, or ARM64 such as a Raspberry Pi 4 or 5): `Imadive-server-0.4.12-linux-x86_64.tar.gz` or `…-linux-aarch64.tar.gz`, installed by the one-line command in the [server guide](https://github.com/waiting4timeout/imadive/blob/main/docs/server.md).

Your folders, people names and index carry over from earlier versions; nothing is indexed again.

Each download can be checked: `SHA256SUMS` lists the files' checksums, and every file carries a signed record of the GitHub build it came from (`gh attestation verify <file> --repo waiting4timeout/imadive`).

## What's new

- **A date range replaces an open year, month or day.** Opening a group's card and then setting *From* or *to* used to keep both date filters, so the range only reached inside the open month. Now setting a range takes over from the open card; the people and the place stay.
- **A security update inside.** The SQLite bundled with Imadive could return uninitialized bytes of the process's memory through ordinary queries, when made to open a database file together with a write-ahead log written by someone else; the bundled version now has it fixed (CVE-2026-119375). A library only you have written to is not a concern; still, this update is recommended.
- **Dependencies are brought up to date.** The weekly round: Rust crates (Tauri and its plugins among them), the Node packages of the UI tests, and the GitHub Actions that build the app.
